# CampusBites

CampusBites is a fictional Islamabad restaurant serving burgers, pizza, biryani, pasta, wraps, sides, and dessert. It is designed for university students, hostel residents, and neighbours in H-11. The site will let customers choose meals in Pakistani rupees and complete a simulated delivery order.

## Local setup

Use Node.js 22.12 or newer. In PowerShell, use `npm.cmd` if your shell blocks `npm.ps1`.

```sh
npm ci
npm run dev
npm run build
```

Open the local address printed by Vite. At the first milestone the home page previews the menu from `src/data/menu.js`.
